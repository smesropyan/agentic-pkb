# ASD-STE100 (Simplified Technical English)

## Word Rules

| Rule | Fix |
|------|-----|
| One word, one meaning — don't vary vocabulary for the same concept | Pick one term and reuse it throughout |
| Use the simplest word that carries the meaning | Swap "utilize" → "use", "prior to" → "before" |
| Avoid unnecessary synonyms and elegant variation | If you called it a "server" once, call it a "server" everywhere |
| Spell out abbreviations and acronyms on first use | Define once, then use consistently |
| Avoid slang, idiom, and figurative language | State the literal meaning |
| Keep articles ("a", "the") — don't drop them in headline style | Write full noun phrases |

## Verb Rules

| Rule | Fix |
|------|-----|
| Use active voice | Name the actor: "the technician tightens the bolt," not "the bolt is tightened" |
| Use simple tenses (simple present, simple past, imperative) | Avoid perfect/continuous/conditional stacking: "had been going to have checked" → "checked" |
| Use imperative mood for instructions | "Remove the panel," not "the panel should be removed" or "you should remove the panel" |
| Don't turn verbs into nouns (nominalization) | "the calibration of the sensor" → "calibrate the sensor" |
| Avoid -ing forms (gerunds/present participles) as nouns or dangling modifiers | "checking the log revealed" → "the log check revealed" or restate with a subject and verb |

## Noun and Clause Rules

| Rule | Fix |
|------|-----|
| Avoid ambiguous pronoun reference | Repeat the noun instead of "it"/"this" when the antecedent could be unclear |
